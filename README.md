# Atividade Bootstrap — Café Aurora

Página responsiva de uma cafeteria fictícia feita com **Bootstrap 5** (via CDN).

**Aluno:** Alexandre · Engenharia de Software · UCSal · Prof. Elton Figueiredo

## Componentes
1. Navbar com menu colapsável
2. Carrossel com setas, indicadores e auto-play
3. Cards em grid responsivo
4. Tabela striped e responsiva
5. Formulário com validação HTML5
6. Modal com overlay

## Como abrir
Abra o arquivo `bootstrap/index.html` no navegador.
No Codespaces, clique com o botão direito no arquivo e escolha **Open with Live Server**.
